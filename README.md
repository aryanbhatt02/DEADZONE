# DEADZONE

A 3D zombie shooter developed using Unity and C#.

## Features

- Player Movement
- Weapons System
- Enemy AI
- Wave-Based Enemy Spawning
- Save System
- In-Game Currency
- Weapon Shop
- Ammo Refill System
- Health Refill System
- Kill Counter
- Collectible System
- UI System
- Audio Integration
- Animation System
- Scene Management

## Technologies

- Unity
- C#
