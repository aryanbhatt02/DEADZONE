# DEADZONE

A 3D zombie shooter developed using Unity and C#.

## Features

- Player Controller
- Weapons System
- Enemy AI
- Wave-Based Enemy Spawning
- Save System
- In-Game Currency
- Weapon Shop
- Ammo Refill System
- Health Refill System
- Gate Repair System
- Kill Count Tracking
- Collectible System
- UI System
- Audio Integration
- 3D Audio Integration
- Animation System
- Scene Management
- Mobile Controls
- Game Optimization

## Technologies

- Unity
- C#
